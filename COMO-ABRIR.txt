ABRIR O SENTIA COM BANCO NO XAMPP

1. Extraia o ZIP inteiro.
2. Copie a pasta Sentia para htdocs do XAMPP. Exemplo: C:\xampp\htdocs\Sentia.
3. No painel XAMPP, inicie Apache e MySQL.
4. Acesse http://localhost/Sentia/.
5. Em Meu registro, clique em Preparar banco local. Outra opção é importar banco/schema.sql no phpMyAdmin.
6. Edite os arquivos pelo VS Code. Para executar com banco, use o endereço do Apache, não Live Server nem file://.

Se Apache/MySQL usam outras configurações, consulte documentacao/BANCO-XAMPP.txt.
ABRIR-SENTIA.cmd apenas abre http://localhost/Sentia/; ele não instala nem inicia o XAMPP.
Para ler os códigos isolados do professor, use entrega-escolar. Para executar, use o projeto completo na raiz.
O Jardim é acessado no site, depois do enigma, e não usa o MySQL.
