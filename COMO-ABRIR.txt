ABRIR O SENTIA

Extraia o ZIP inteiro. Abra a pasta Sentia no VS Code.
O site normal e o Jardim abrem com index.html, diretamente ou pelo Live Server.
O Jardim não usa MySQL nem PHP. As seis atividades do site também funcionam com o plano pessoal no navegador.
ABRIR-SENTIA.cmd abre o index.html local.

SÓ O MODO COMPARTILHADO DO REGISTRO USA XAMPP
1. Copie a pasta Sentia para htdocs do XAMPP.
2. Inicie Apache e MySQL.
3. Acesse http://localhost/Sentia/ ou use ABRIR-BANCO-XAMPP.cmd.
4. Em Meu registro, selecione Registro compartilhado · MySQL.
5. Clique em Preparar banco local se aparecer, ou importe banco/schema.sql no phpMyAdmin.

Os dois modos do registro são independentes; importar o plano pessoal é opcional e explícito.
O enigma do site continua abrindo o Jardim normalmente.
Veja documentacao/CONFERENCIA-PWI.md para os requisitos e LEIA-ME.txt para o projeto completo.
