SENTIA — PACOTE COMPLETO

Esta pasta contém o site educativo, o Jardim dos Ecos, os arquivos de imagem e o portfólio.

PARA USAR
1. Extraia o ZIP inteiro. Não abra o HTML de dentro do arquivo compactado.
2. No Visual Studio Code, use Arquivo > Abrir Pasta e selecione Sentia.
3. Abra index.html com Live Server, ou dê dois cliques em ABRIR-SENTIA.cmd para abrir no navegador.
4. O Jardim é acessado pela página O Jardim do próprio SENTIA, após as descobertas do site.
5. Mantenha css, js e assets junto de index.html e jardim.html.

CONTEÚDO
assets: 834 arquivos de imagem existentes, incluindo sprites, cenários, efeitos e pranchas.
css e js: arquivos separados do projeto funcional.
entrega-escolar: cópias isoladas de HTML, CSS e JavaScript para avaliação. O HTML-puro não importa o visual nem as interações; execute o index.html da raiz para usar o projeto completo.
portfolio: capturas das páginas e portfólio Excalidraw.
documentacao: roteiro e contexto do projeto.

ESTADO DO JOGO
Inclui conversas recorrentes por descobertas, abertura com quatro moradores, desbloqueio dos quartos, medidor de sanidade, poses de diálogo e cenário, variações de combate e ações das mãos ao examinar e usar objetos.
É possível continuar um save anterior. Para conhecer a nova abertura, exporte o progresso pela Pausa e depois escolha Começar outra partida.
Os testes incluem uma sequência contínua da abertura até a arena de Beerus, e verificações separadas dos desfechos posteriores, dos controles e das molduras.
A duração narrativa de 2–3 horas ainda precisa ser conferida numa partida humana completa.

ENTREGA ESCOLAR
Comentários explicam os blocos principais. O aluno deve estudar e revisar o material; o projeto recebeu assistência de IA.
O endereço público do GitHub nos comentários HTML ainda deve ser substituído pela URL real após a publicação. Não foi feita publicação automática.
Os conceitos exigidos nas apostilas ainda precisam ser comparados com a lista de avaliação do professor.
